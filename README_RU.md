# TEMA Bruce RU XL 2.0 — Android / Termux / GitHub

## Что это такое

**Целевая плата:** LilyGO T-Embed CC1101 (ESP32-S3), профиль PlatformIO `lilygo-t-embed-cc1101`, штатный горизонтальный экран 320×170 пикселей.

**Исходный проект:** https://github.com/BruceDevices/firmware  
**Проверенная версия исходников (pin):** `a59213f3ec6cd302fa32c2042b2700c9c24d991a`.

Используется **полная**, не Lite-сборка оригинального Bruce. Изменяется только отрисовка пользовательского интерфейса; действия радиомодулей, Wi-Fi, NFC, IR, JS и т. д. намеренно не изменяются.

Это **не официальный релиз команды Bruce**. Патч сохраняет оригинальные английские названия внутри программной логики, переводит их только в момент отображения, чтобы не нарушить условия и обработчики меню.

### Русский и увеличение шрифта

- Дополненный словарь примерно из 399 английских обозначений и их русских вариантов, включая названия меню/подменю, настройки, команды и некоторые сообщения.
- Собственный встроенный битовый шрифт с кириллицей А-Я, а-я, Ё/ё. Глифы генерируются *во время сборки* из установленного на сервере DejaVu Sans, файлы шрифтов в архиве не распространяются.
- Основные надписи в обычном меню имеют высоту до 32 пикселей вместо стандартных примерно 16 пикселей (**×2 по линейному размеру**, не двукратная площадь).
- На небольшом дисплее умещаются 3 крупных строки; длинные названия выбранных пунктов прокручиваются.
- Перевод применяется к главному меню, стандартным спискам, подменю, просмотру файлов, части заголовков и уведомлений.

**Граница готовности:** это расширенная русификация навигации, а НЕ гарантированные 100% всего интерфейса Bruce. Некоторые специализированные экраны, диагностические сообщения, веб-страницы, скрипты и динамические строки пока могут остаться английскими/мелкими. В архив добавлен `translation_audit.py` для инвентаризации таких строк после клонирования исходников. Точный итог требует сборки и проверки на физическом устройстве. Сборка НЕ проверялась на физическом T-Embed.

## Способ 1. Весь цикл из Termux + GitHub на Android

### 1. Установить приложения

- Termux (лучше актуальный F-Droid/GitHub релиз), Android-браузер.
- Зарегистрированный GitHub-аккаунт.
- ZIP из этого ответа, сохранённый в папку `Download` Android.

Запустить Termux и по очереди выполнить:

```bash
pkg update -y && pkg upgrade -y
pkg install -y git gh unzip python
termux-setup-storage
```

**Важно:** Android должен показать запрос разрешения доступа к файлам. Разреши его. При необходимости перезапусти Termux после предоставления доступа. Файл в командах ниже должен находиться по пути `/sdcard/Download/TEMA_Bruce_RU_XL_2_build_kit.zip`.

### 2. Распаковать ZIP

```bash
mkdir -p ~/projects/tema-bruce-ru-xl
unzip -o /sdcard/Download/TEMA_Bruce_RU_XL_2_build_kit.zip -d ~/projects/tema-bruce-ru-xl
cd ~/projects/tema-bruce-ru-xl
ls -la
```

Проверь, что здесь есть `tema_patch.py`, `ru_extra.tsv`, `README_RU.md` и скрытая папка `.github`.

### 3. Войти в GitHub через Termux

```bash
gh auth login -h github.com -p https -w
gh auth setup-git
gh auth status
```

В процессе входа GitHub CLI предложит код авторизации и страницу для подтверждения. Открой страницу в браузере, войди в **свой** аккаунт и введи код. **Не передавай мне токен или пароль**.

### 4. Создать репозиторий и отправить проект

Укажи собственные имя и адрес для Git-автора. GitHub позволяет использовать адрес `...@users.noreply.github.com`, если он настроен в аккаунте. Значения ниже надо заменить на свои:

```bash
git config --global user.name "ТВОЙ_GITHUB_НИК"
git config --global user.email "ТВОЙ_EMAIL_ДЛЯ_GIT"
git init -b main
git add .
git commit -m "TEMA Bruce RU XL 2.0 build system"
gh repo create tema-bruce-ru-xl --public --source=. --remote=origin --push
```

После этого появится репозиторий `https://github.com/ТВОЙ_GITHUB_НИК/tema-bruce-ru-xl`.

Если имя репозитория уже занято в твоём аккаунте, используй другое, например `tema-bruce-russian`.

### 5. Собрать **полную прошивку** на GitHub Actions

Из той же папки в Termux:

```bash
gh workflow list
gh workflow run build-tema-ru-xl.yml
gh run list --workflow build-tema-ru-xl.yml --limit 5
```

Для просмотра статуса в браузере открой свой репозиторий, затем `Actions → TEMA Bruce RU XL 2.0 - T-Embed CC1101`.

Найди последний запуск и убедись, что весь процесс завершился зелёной отметкой `Success`. Красный значок `Failure` означает, что готовой проверенной прошивки нет; смотри в `Actions → run → шаг с ошибкой`, либо в Termux:

```bash
gh run list --workflow build-tema-ru-xl.yml --limit 5
```

После успешной сборки внизу страницы запуска появится `Artifacts → TEMA-Bruce-RU-XL-TEmbed-CC1101`. Это ZIP, содержащий **собранный BIN**, журнал сборки, отчёт о непереведённых кандидатах и SHA256.

Скачать артефакт через Termux можно так:

```bash
mkdir -p /sdcard/Download/TEMA-Bruce
# Впиши номер (ID) успешного run, который показывает gh run list:
gh run download НОМЕР_RUN -n TEMA-Bruce-RU-XL-TEmbed-CC1101 -D /sdcard/Download/TEMA-Bruce
ls -lh /sdcard/Download/TEMA-Bruce/
```

Номер run вводи без угловых скобок. Если CLI показывает не число, открой нужную сборку на GitHub в Chrome и скачай `Artifacts` вручную.

## Способ 2. Только сайт GitHub, если Termux не нужен

1. Создай пустой публичный репозиторий `tema-bruce-ru-xl`.
2. Загрузи в корень репозитория `tema_patch.py`, `ru_extra.tsv`, `translation_audit.py` и `README_RU.md`.
3. Создай файл по пути `.github/workflows/build-tema-ru-xl.yml`, вставив текст из нашего архива.
4. Перейди в `Actions`, открой `TEMA Bruce RU XL 2.0 - T-Embed CC1101`, нажми `Run workflow`.
5. Скачай артефакт после `Success`.

## Как устанавливать BIN на T-Embed

1. **Перед прошивкой** сохрани важные файлы с microSD и внутренней памяти (если доступна), запиши свои настройки. Перепрошивка или стирание флеш может их удалить. Не меняй `bruce.conf` на случайный файл.
2. Проверь, что файл называется примерно `Bruce-lilygo-t-embed-cc1101...bin`. Не бери образ для простого `lilygo-t-embed` без CC1101 и не выбирай `Plus`, если модель платы не Plus.
3. Используй Android-приложение, **которое реально поддерживает выбор своего локального BIN**, передачу по OTG и ESP32-S3. На твоём установленном Bruce App поддержка выбора локального BIN пока не подтверждена. В каталоге прошивок нельзя подменять файл лишь по похожему названию.
4. На T-Embed CC1101 для режима загрузчика удерживай **нажатым энкодер**, нажми `RST` на плате и затем отпусти кнопки, как описано в официальном Web Flasher Bruce.
5. **Только для объединённого образа** адрес записи должен быть `0x0` (`0x00000`). Не записывай отдельный `.pio/.../firmware.bin` по этому адресу: это иной формат.
6. После успешной записи перезагрузи устройство и проверь: экран, колёсико, кнопку возврата, список файлов, работу microSD, функции RF и IR.

**Резервный вариант восстановления:** официальный Bruce Web Flasher — https://bruce.computer/flasher . Там можно вернуть стандартную прошивку именно для `LilyGo T-Embed CC1101`. Сайт в мобильном Chrome может не поддерживать прошивку по USB; тогда используй совместимое Android-приложение или компьютер. Не запускай полное стирание флеш без резервных копий.

### Если есть компьютер с Linux / macOS / Windows

После успешной сборки объединённый `.bin` можно записать проверенным esptool, указав правильный порт и файл. Общий вид:

```bash
python -m esptool --chip esp32s3 --port /dev/ttyACM0 write_flash 0x0 Bruce-lilygo-t-embed-cc1101.bin
```

Путь `/dev/ttyACM0` здесь **пример Linux**, на твоём компьютере порт/имя файла может быть другим. В обычном непривилегированном Termux этот путь обычно отсутствует и простой вызов esptool не работает: Android выдаёт доступ к USB иначе.

## Как переводить новые пункты

Открой `ru_extra.tsv` и добавляй строки **через табуляцию**, например:

```text
Start pairing    Начать сопряжение
```

В реальном файле между колонками должна быть настоящая клавиша TAB, а не несколько пробелов. Не меняй английские строки исходного Bruce и идентификаторы функций! После изменения словаря отправь изменения через:

```bash
git add ru_extra.tsv
git commit -m "Add Russian UI translations"
git push
```

Изменение файла запускает Actions автоматически (также можно вручную через `gh workflow run`). После сборки открой `localization-audit.txt`: там **кандидаты** на оставшиеся английские строки, а не точная метрика покрытия. Следующий шаг для полностью русифицированного интерфейса — детально доработать специализированные экраны, не затрагивая функции.

## Заметки по стабильности и безопасности

- Ревизия Bruce специально зафиксирована: она подтверждена в исходниках для подготовки патча. Это не обещание, что прошивка самая новая; обновления upstream потребуют повторной проверки.
- Если скрипт останавливается с `Upstream changed` или `expected exactly one`, он специально не внедряет патч в неизвестную структуру исходников.
- Реальная сборка ещё **не запускалась** в этой среде: здесь нет доступа к загрузке зависимостей GitHub/PlatformIO для полной компиляции. Не путать синтаксический тест Python с успешной компиляцией C++ или реальной прошивкой.
- Использование радиоинструментов допустимо только для собственных устройств или при разрешении владельца.
- Исходный Bruce лицензирован по AGPL-3.0. При публикации изменённой прошивки соблюдай условия открытой лицензии и предоставляй соответствующий исходный код и изменения.
